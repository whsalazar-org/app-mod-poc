# app-mod-poc

This repository will demonstrate best practices for using GitHub Copilot to migrate a legacy application to a modern architecture.

The project will focus on practical, repeatable migration workflows, including:
- Assessing legacy code and identifying modernization priorities.
- Planning incremental refactors to reduce risk.
- Using Copilot effectively for code transformation, testing, and documentation.
- Validating behavior with regression tests during each migration step.
- Capturing migration decisions and patterns that can be reused across teams.
